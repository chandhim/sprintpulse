FAQ

How do I hide the side panel?

Click the hide button in the panel header, press Esc, or use the browser's own close (X) button on the panel. Click the toolbar icon to bring it back.

Does it follow me between tabs?

Yes. The panel re-detects the active tab: switch to a different Jira or Trello board and it resets to that board. Switching to a non-board tab keeps your last result on screen only if it came from demo data.

Where does my data go?

Nowhere. Requests are read-only GETs run inside your own board tab, and results are stored only in your browser.

Which permissions does it need?

sidePanel, scripting, storage, plus access to *.atlassian.net and trello.com so it can follow tab changes without you re-clicking the icon.

Jira Server / Data Center?

Not supported yet. Jira Cloud Scrum boards with an active sprint only.
